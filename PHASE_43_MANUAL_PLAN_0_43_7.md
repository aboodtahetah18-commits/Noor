# P43.7 — Manual Plan Builder

- Removed automatic default budget-category seeding from onboarding.
- WF-006 now starts with a manual line-item builder.
- The user controls each item name, allocation group, and planned amount.
- Items are created together with the first financial-plan draft.
- Existing active categories are reused by name when applicable; existing user data is not deleted.
- No migration is required for this UI/domain-flow change.
