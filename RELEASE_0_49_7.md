# Release 0.49.7

## Added
- Modal-first interaction architecture.
- Shared ActionDialog component.
- Dialog-first CRUD for accounts, obligations, budget categories and high-frequency goal actions.
- Dialog-first profile edit and recurring obligation state changes.
- P49.7 quality-gate verification.

## Changed
- Main resource pages now prioritize summary/list content and move secondary interactions into dialogs.
- Action groups use a single horizontal row where space permits.

## Compatibility
- Existing route pages remain available as fallback during the transition.
