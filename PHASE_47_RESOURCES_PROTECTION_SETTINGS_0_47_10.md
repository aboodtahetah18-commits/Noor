# P47.9 + P47.10 — Resources, Income, Protection & Settings

## P47.9
- Accounts redesigned as a liquidity map with active/inactive separation.
- Obligations redesigned as a due-date/status timeline with reserved amount context.
- Income index is now a real monitoring page instead of redirecting directly to the entry form.
- Expected income and posted income are visually separated; actual income remains the only liquidity-changing source.

## P47.10
- Savings redesigned as protected-allocation execution progress.
- Emergency fund redesigned as a protection layer with current balance, target, progress, and cycle allocation.
- Settings redesigned as an administration hub with profile, rules, references, and recurring obligation controls.
- No new financial formulas, target thresholds, or automatic reallocations were introduced.

## Responsive
Desktop uses dense analytical layouts; mobile collapses to touch-friendly cards and timelines rather than squeezing desktop tables.

## Database
No migration required. Migration count remains 64.
