# P47.7 + P47.8 — Analysis, Advisor, Alerts & Decision Center

## P47.7 — Reports and future financial pressure

- Reframes reports as an analysis workspace rather than disconnected white cards.
- Current cycle report now uses the P47 analysis shell and KPI hierarchy.
- Historical analysis and contextual learning share the same visual analysis language.
- Future pressure is presented as a financial radar with the existing deterministic forecast data, scenarios, packages, learning, and outcome verification preserved.
- No new forecast formula, risk score, or financial threshold was introduced.

## P47.8 — Advisor, alerts and decision audit

- Advisor page becomes a recommendation decision center with exact total counters, clearer filtering, recommendation types, priority, reason evidence, and direct detail actions.
- Alert Center groups operational attention by severity and lifecycle state while preserving the existing alert-source truth model.
- Decision log becomes an audit timeline with source, event type, affected count, amount, reason, and optional impact payload.
- Mobile layouts use stacked cards/action rows instead of squeezing desktop structures.

## Financial integrity

This release changes presentation/read composition only. It does not modify:
- recommendation rule triggers;
- alert source conditions or lifecycle transitions;
- financial-pressure formulas;
- decision event semantics;
- transaction, budget, goal, or funding calculations.

## Database

No new migration. Migration count remains 64.
