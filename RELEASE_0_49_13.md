# Release 0.49.13

P49.13 applies the approved mobile compact UX language globally across the protected application.

Highlights:
- compact branded mobile header;
- icon-only alerts/settings;
- logo/profile trigger;
- equal five-tab bottom navigation;
- reusable collapsible filters;
- compact transaction and advisor filters;
- two-column mobile forms where appropriate;
- horizontal action strips;
- reduced card/KPI/page spacing.

No database migration. Next planned stage: P50 Full System Acceptance.
