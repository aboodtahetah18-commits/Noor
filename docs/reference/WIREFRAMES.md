# 1. الهدف من الوثيقة

تحدد هذه الوثيقة المخطط الوظيفي الكامل لواجهات النظام قبل التصميم النهائي والبرمجة.

الهدف هو تحديد:

* ماذا يظهر في كل شاشة.
* ترتيب العناصر.
* الإجراء الرئيسي.
* الإجراءات الثانوية.
* محتوى Desktop.
* محتوى Mobile.
* الحالات المختلفة للشاشة.
* تدفقات النوافذ والنماذج.
* ما يظهر وما يخفى.
* كيفية ربط الشاشات ببعضها.

هذه الوثيقة ليست Mockup نهائيًا بالألوان.

وإنما:

```text
UX Architecture
+
Design System
↓
Screen Specification
```

# 109. قاعدة الحوكمة النهائية

أي تعديل على Prototype يجب ألا يغير:

```text
Business Rule
State
Workflow
Financial Meaning
```

بسبب رغبة بصرية فقط.

إذا كشف Prototype أن تجربة معينة تحتاج تغييرًا في المنطق، يتم الرجوع إلى المرجع الأصلي وتعديله أولًا.

ولا يتم حل التعارض داخل التصميم وحده.
