# Vercel deployment hold

Status: ACTIVE

- Automatic Git deployments to Vercel are disabled.
- No preview or production deployment may be created while this hold is active.
- Work continues in GitHub/CI until the platform is considered ready.
- Re-enabling Vercel requires explicit user approval for deployment.
- When approval is given, re-enable deliberately, deploy the approved revision, verify it, then decide whether to keep automatic deployments disabled.
