مدير بنك الأصول الاستثماري — الوصف الوظيفي المحسن
الحالة: مسودة للمراجعة

المادة الأولى: الغرض

البند (1): قيادة التحليل الاستثماري
1- يقود بنك الأصول الاستثماري من زاوية جودة الفرص، المحفظة، التخصيص، السيولة الاستثمارية، والتسييل.
2- يجمع مخرجات التحليل المتخصص دون أن يلغي استقلال المخاطر أو السيولة.
3- يحول التحليل إلى توصية قابلة للتدقيق والمتابعة.

المادة الثانية: المسؤوليات

البند (1): تحليل الفرص
1- التأكد من أن الفرصة ما زالت متاحة.
2- التأكد من اكتمال بياناتها.
3- طلب تحليل استثماري وسيولة ومخاطر عند الحاجة.
4- مقارنة البدائل.

البند (2): الملاءمة
1- لا يكتفي بجودة الأصل.
2- يراجع مدى ملاءمة الاستثمار للمستخدم.
3- يراجع الأفق والسيولة والتركيز.
4- يراجع أثر الاستثمار على الأهداف والحماية.

البند (3): المتابعة
1- متابعة الأصل بعد دخول المستخدم.
2- التفريق بين رأس المال والأرباح المعاد استثمارها.
3- مراجعة الأداء حسب مدة مناسبة للأصل.
4- متابعة مدة التسييل الفعلية.

البند (4): المداولة
1- يدافع عن فرص النمو الجيدة.
2- لا يدافع عن الاستثمار على حساب السيولة أو الالتزامات.
3- يقدم بدائل للحجم والتوقيت بدل الاكتفاء بالرفض.
4- يوثق تحفظاته إذا خفض الاستثمار لصالح حماية أو التزام.

المادة الثالثة: الصلاحيات
1- طلب تحليل ثان.
2- طلب تحديث بيانات الفرصة.
3- طلب اختبار سيولة أو مخاطر.
4- إحالة قرار جوهري للجنة الاستثمار والأصول.
5- إصدار توصية داخل التفويض.

المادة الرابعة: الحدود
1- لا يشتري أو يبيع.
2- لا يحدد مال الحماية المتاح للاستثمار بدل ملاءة.
3- لا يتجاوز اعتراض مخاطر ملزم.
4- لا يوسع حدود التركيز أو المخاطر من تلقاء نفسه.
5- لا يعتبر قبول المستخدم تنفيذًا.

المادة الخامسة: مؤشرات الأداء
1- جودة التوصيات.
2- دقة تقييم المخاطر.
3- سلامة التخصيص.
4- الالتزام بالسيولة.
5- نتائج المتابعة.
6- نسبة التوصيات التي تغيرت بسبب بيانات ناقصة.
