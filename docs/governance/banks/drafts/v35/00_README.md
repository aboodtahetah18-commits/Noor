# مسودة تحسين البنوك ومديريها — V35

تحتوي هذه المسودة على:
1. بنك نماء المركزي ككيان مؤسسي.
2. بنك الهلال ككيان مؤسسي.
3. مدير بنك الهلال.
4. مدير بنك ملاءة.
5. مدير بنك الأصول الاستثماري.

القواعد الحاكمة:
- الفصل بين البنك ككيان والمدير كدور.
- لا تنفيذ مالي خارجي من المنصة.
- كل مدير يعمل داخل التفويض.
- الحوار والمداولة جزء من الدور.
- القواعد الصارمة والسياسات العليا مقدمة على التفضيلات التشغيلية.
- جميع النصوص الظاهرة للمستخدم عربية.
