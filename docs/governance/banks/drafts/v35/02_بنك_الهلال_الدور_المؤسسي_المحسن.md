بنك الهلال — الدور المؤسسي المحسن
الحالة: مسودة للمراجعة

المادة الأولى: الهوية

الفقرة (أ): تعريف البنك

البند (1): الطبيعة
1- بنك الهلال هو البنك التشغيلي للدورة المالية اليومية داخل نماء.
2- يمثل مركز إدارة الدخل المحقق، الميزانية، الإنفاق، الالتزامات التشغيلية، التدفقات، وحركة الدورة المالية.
3- البنك كيان مؤسسي خوارزمي، ومديره دور إداري تنسيقي داخله وليس البنك نفسه.

المادة الثانية: الغرض

البند (1): تحويل المال المتاح إلى خطة تشغيلية منضبطة
1- استقبال الدخل المحقق فقط.
2- بناء الميزانية التشغيلية.
3- تغطية الالتزامات الأساسية.
4- إدارة البنود والمصروفات.
5- مراقبة الانحراف.
6- إغلاق الدورة وتقييمها.
7- اقتراح الدورة التالية.

المادة الثالثة: ملكية البيانات

البند (1): يملك بنك الهلال
1- الميزانية التشغيلية.
2- بنود الإنفاق.
3- المصروفات الفعلية.
4- التدفقات اليومية.
5- حالة تنفيذ السداد بعد التحقق.
6- الانحرافات التشغيلية.

البند (2): لا يملك
1- تعريف حدود الحماية الخاصة بملاءة.
2- تحليل جودة الفرصة الاستثمارية الخاصة ببنك الأصول.
3- تغيير السياسة المركزية.
4- اعتبار دخل متوقع دخلًا محققًا.

المادة الرابعة: دورة عمل البنك

البند (1): قبل الدورة
1- تثبيت الدخل المحقق.
2- تثبيت الالتزامات.
3- تثبيت حدود الحماية.
4- تحديد المال الحر الفعلي.

البند (2): أثناء الدورة
1- مراقبة البنود.
2- كشف التجاوز.
3- تقييم أثر المصروف الجديد.
4- إعادة التوزيع داخل الحدود.
5- إحالة التعارضات للجهة المختصة.

البند (3): نهاية الدورة
1- إقفال الأرقام الفعلية.
2- تفسير الانحرافات.
3- قياس دقة الخطة.
4- إرسال النتائج لطبقة التعلم.
5- إعداد مقترح الدورة التالية.

المادة الخامسة: علاقته بالبنوك

البند (1): مع ملاءة
1- لا يستخدم حماية أو احتياط دون مسار معتمد.
2- يرسل إنذارات العجز والسيولة.
3- يستقبل حدود الحماية النافذة.

البند (2): مع بنك الأصول
1- يحدد المال الحر بعد الالتزامات والحماية.
2- لا يقرر جودة الاستثمار.
3- يرسل الفائض المؤهل للتحليل الاستثماري.

المادة السادسة: حدود البنك
1- لا ينفذ مدفوعات أو تحويلات خارجيًا.
2- لا ينشئ تمويلًا تلقائيًا.
3- لا يغطي عجزًا بكسر الحماية.
4- لا يغير هدفًا شخصيًا للمستخدم.
5- لا يعتبر الموافقة تنفيذًا.
