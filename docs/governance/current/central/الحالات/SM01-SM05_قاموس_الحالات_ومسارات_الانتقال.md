# SM01–SM05 | قاموس الحالات ومسارات الانتقال

**الإصدار:** 1.0  
**الجهة المالكة:** بنك نماء المركزي

## SM01 | دورة حياة الحالة
الحالات الأساسية: جديدة، تحتاج بيانات، جاهزة للتحليل، تحت التحليل، تحتاج مراجعة، بانتظار اعتماد، مصعدة، بانتظار المستخدم، بانتظار التنفيذ، تحت التحقق، تحت المتابعة، مغلقة، أعيد فتحها.

الانتقالات الأساسية:
جديدة → تحتاج بيانات/جاهزة للتحليل → تحت التحليل → تحتاج مراجعة → بانتظار اعتماد → بانتظار المستخدم → بانتظار التنفيذ → تحت التحقق → تحت المتابعة → مغلقة.  
يجوز العودة للتحليل أو التصعيد عند الحاجة، ويجوز مغلقة → أعيد فتحها → تحت التحليل عند ظهور سبب مشروع.

لا يسمح بالقفز من التحليل إلى التنفيذ أو من الاعتماد إلى تحديث الواقع المالي.

## SM02 | دورة حياة القرار
مسودة → تحت التحليل → موصى به → يحتاج اعتماد → معتمد/مرفوض → يحتاج إعادة تحقق أو منتهي الصلاحية أو انتقل للتنفيذ.  
**معتمد ≠ منفذ.**

## SM03 | دورة حياة التنفيذ
لم يبدأ → بانتظار المستخدم → أكد التنفيذ → يحتاج إثبات/تحت المطابقة → تنفيذ كامل أو جزئي أو مختلف أو متعذر أو مرفوض أو منتهي الصلاحية. التنفيذ الكامل فقط يسمح بتحديث الواقع وفق ما تحقق.

## SM04 | دورة حياة التصعيد والاستثناء
التصعيد: اكتشاف سبب → إعداد الملف → مصعد → يحتاج معلومات/تحت المراجعة → تم الحسم → عاد للمسار أو تحول إلى تغيير مؤسسي.  
الاستثناء: طلب → فحص القاعدة → غير مسموح أو تحت التحليل → يحتاج اعتماد → معتمد مؤقتًا/مرفوض → انتهى → مراجعة → اقتراح تغيير عند الحاجة.

## SM05 | دورة حياة التغيير المؤسسي
فكرة تغيير → مقترح مسجل → تحت الدراسة → مراجعة الجهات → اختبار → يحتاج اعتماد → معتمد → مجدول للنفاذ → نافذ → تحت المراقبة → يحتاج تعديل إضافي أو ملغى.

كل انتقال يجب أن يسجل حالته السابقة والجديدة ووقته ومالكه وسببه ومرجعه.
