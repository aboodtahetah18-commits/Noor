# A01–A05 | الحزمة المركزية للصلاحيات والاعتمادات

**الإصدار:** 1.1  
**الحالة:** مسودة بناء موسعة  
**الجهة المالكة:** بنك نماء المركزي

## A01 | الصلاحيات المؤسسية
تفرق نماء بين سلطة إنشاء الحالة، التحليل، طلب المعلومات، إعادة التحليل، المراجعة، الاعتماد، الرفض، الإيقاف، التصعيد، إعادة الفتح والإغلاق. كل صلاحية مستقلة ولا تنتقل ضمنيًا مع المسمى.

### المستخدم
يملك إنشاء الطلب، تقديم البيانات، قبول أو رفض أو تأجيل البدائل المسموحة، طلب التفسير وإعادة التقييم، التنفيذ الخارجي وتقديم الإثبات. لا يملك تجاوز قاعدة صارمة أو تغيير سياسة أو صلاحية أو حذف سجل.

### مجلس نماء الأعلى
يعتمد التغييرات المؤسسية العليا وإنشاء أو إلغاء الكيانات أو السلطات الكبرى وما يتجاوز المحافظ. لا يدير التشغيل اليومي ولا ينفذ المال.

### المحافظ
يفتح مراجعة مركزية، يطلب البيانات والآراء وإعادة التحليل، ينقل القضية إلى مسار مركزي، يشكل أو يحيل إلى لجنة ضمن صلاحياته، يوقف قرارًا مركزيًا عند تغير جوهري، ويصعد للمجلس. لا يتجاوز قاعدة صارمة ولا ينفذ المال.

### بنك نماء المركزي
مالك الإطار المؤسسي والحوكمة والمخاطر المركزية وجودة البيانات والصلاحيات وسجل الأثر والتعلم المركزي. يمكنه إعادة تصنيف القضية، تغيير البنك القائد، إضافة بنك أو مسؤول، طلب محاكاة أو تعليق اعتماد أو التصعيد.

### مدير البنك
هو السلطة التشغيلية المباشرة داخل البنك. يملك قبول الحالة وتوزيع العمل وطلب المعلومات وإعادة التحليل والاعتماد داخل التفويض والإيقاف المؤقت والتصعيد وإعادة الفتح والمتابعة. لا يملك التنفيذ المالي أو تجاوز قاعدة صارمة أو تعديل سياسة أو لائحة مركزية منفردًا.

### أصحاب المسؤوليات
- **الميزانية والإنفاق:** تحليل الميزانية والانحراف، طلب إعادة الحساب أو التصنيف، ورفع خطر الإنفاق غير المستدام.
- **الالتزامات:** فحص الديون والاستحقاقات، طلب محاكاة مستقبلية ورفع خطر السداد.
- **الأهداف:** حماية أموال الأهداف، إعادة حساب موعد الإنجاز، وطلب إعادة الجدولة.
- **الاستثمار:** تقييم الأهلية والمخاطر والسيولة والتركيز وقابلية الخروج.
- **السيولة والحماية:** المرجع التخصصي للاحتياط والسيولة والطوارئ وقدرة تحمل الصدمات؛ الاعتراض المبني على قاعدة صارمة لا يتجاوز بالتصويت.
- **المستشار الاقتصادي:** تحليل وسيناريوهات اقتصادية دون اعتماد مالي منفرد.

### مركز العمليات والمطابقة
يستقبل الأدلة ويطابقها ويكتشف التكرار ويصنف التنفيذ ويطلب إثباتًا إضافيًا، ولا يغير القرار أو ينشئ استثناءً.

### التفويض والتعارض
كل تفويض مؤقت يحدد المفوض والمفوض له والنطاق والحدود والبداية والنهاية. عند تعارض الصلاحيات يحسم الغرض الأساسي والاختصاص والمال المتأثر والخطر والتفويض، ثم المركزي إذا استمر الخلاف. لا توجد صلاحية ضمنية.

## A02 | الصلاحيات المالية
- الإنفاق اليومي: يقوده الهلال ويعتمده مدير الهلال داخل التفويض وينفذه المستخدم.
- استخدام الاحتياط: يقوده ملاءة مع رأي مسؤول السيولة والحماية.
- الاستثمار الجديد: يقوده الأصول مع رأي مسؤول الاستثمار وفحص الحماية.
- الاستثمار من الاحتياط: يتطلب ملاءة + السيولة والحماية + الأصول + الاستثمار.
- التمويل أو التزام جديد: يشارك مسؤول الالتزامات والسيولة والحماية ولا يعتمد إذا كسر التغطية الأساسية.
- السداد المبكر: يوازن الوفر مع أثر السيولة والحماية.
- أموال الأهداف: لا تعاد تخصيصها بصمت.
- القرار المالي الخارجي دائمًا: اعتماد → مهمة للمستخدم → تنفيذ المستخدم → إثبات → مطابقة → تحديث الواقع.

## A03 | صلاحيات السياسات والحوكمة
يجوز اقتراح السياسة من المحافظ أو المركزي أو مدير بنك أو لجنة أو مسؤول أو مستشار أو مركز العمليات أو نظام التعلم، لكن الاقتراح لا يصبح نافذًا. الصياغة والمراجعة والاختبار والاعتماد والنفاذ أدوار مستقلة. أي تغيير في الصلاحيات أو القواعد الحاكمة يحتاج مراجعة مركزية وإصدارًا جديدًا.

## A04 | صلاحيات الحالات والتصعيد
تبقى الحالة في البنك إذا كانت ضمن الاختصاص والتفويض والمخاطر المقبولة. تصعد من المسؤول للمدير عند خطر أو تعارض أو نقص بيانات حساس، ومن المدير للمركزي عند تعدد البنوك أو تجاوز التفويض أو الاستثناء، ومن المركزي للمحافظ عند الأثر العالي أو الحاجة لاعتماد أعلى، وللجنة عند الحاجة لمداولة متعددة، وللمجلس في التغييرات العليا.

## A05 | صلاحيات التنفيذ والمتابعة
الاعتماد لا يعني التنفيذ. المستخدم وحده ينفذ الحركة المالية الخارجية. مركز العمليات يتحقق من التنفيذ، والبنك المختص يحدث الحقيقة المالية بعد التحقق، وأصحاب المسؤوليات يتابعون أثر التنفيذ، ومدير البنك يراقب القرارات غير المنفذة والجزئية والمختلفة ويعيد التحليل عند الحاجة.
