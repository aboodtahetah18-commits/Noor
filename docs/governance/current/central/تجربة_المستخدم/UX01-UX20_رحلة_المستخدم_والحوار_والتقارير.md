# UX01–UX20 | رحلة المستخدم والحوار والتفسير والتقارير

**الإصدار:** 1.0  
**الجهة المالكة:** بنك نماء المركزي

## رحلة المستخدم
إنشاء الحساب والدخول → التعارف والتأسيس → بناء ذاكرة الحياة المالية → الوضع المالي الأولي → التشغيل اليومي → القرارات والتنبيهات → تنفيذ المستخدم → المتابعة → التعلم والتخصيص → المراجعات الدورية.

## جلسة التأسيس
يقودها محافظ بنك نماء المركزي، بسؤال رئيسي واحد في كل مرة، مع استخدام ما تعرفه المنصة وعدم إعادة الأسئلة. الأولوية لطبيعة الدخل والالتزامات والسيولة والحماية والأهداف والاستثمار والتفضيلات، ويتغير الترتيب حسب السياق.

## جاهزية الملف
تفصل المنصة بين جاهزية أساسية، تشغيلية، وجاهزية لقرارات حساسة، بدل ثنائية "مكتمل/غير مكتمل".

## المحادثة
الواجهة طبيعية، لكن كل رسالة مهمة قد تنتج حقيقة أو تحديث بيانات أو حالة أو قرارًا أو مهمة أو متابعة. لا تعرض معرفات تقنية للمستخدم.

## تفسير القرار
كل توصية مهمة تشرح:
- ماذا نرى؟
- ماذا نقترح؟
- لماذا؟
- ما المخاطر؟
- ما البدائل؟
- ماذا يحتاج المستخدم أن يفعل؟

الرفض لا يعرض كـ"مرفوض" فقط، بل يشرح القاعدة والسبب والبدائل. درجة الثقة والمخاطر تعرض بلغة تفسيرية، لا برقم أو وصف مبهم فقط.

## لوحات المتابعة
### المستخدم
الوضع الحالي، ما يحتاج انتباهًا، القرارات المفتوحة، المهام، تقدم الأهداف، الحماية والالتزامات القريبة.

### مدير البنك
الحالات الجديدة وتحت التحليل وتحتاج بيانات أو اعتماد والمتأخرة والمصعدة وبانتظار المستخدم وتحت المتابعة والتنبيهات المهمة.

### المحافظ
وضع كل بنك، الحالات الحرجة، التعارضات، التصعيدات، التغييرات المؤسسية، جودة البيانات، أداء المتابعة والمخاطر النظامية.

### أصحاب المسؤوليات
كل مسؤول يرى فقط ما يحتاجه لاختصاصه.

## التقارير
التقرير الأسبوعي يوضح ماذا تغير وتحسن وتراجع وما يحتاج انتباهًا والقرارات المفتوحة وما يحتاج المستخدم فعله وما المتوقع. التقرير الشهري أعمق ويشمل الميزانية والالتزامات والأهداف والحماية والاستثمار والقرارات والانحرافات والتعلم والتوصيات.

## عدم الإغراق
الواجهة اليومية تعرض النتيجة والسبب والإجراء أولًا، وتتيح التوسع للبيانات والحسابات والرأي التخصصي وسجل التنفيذ والمتابعة. في الطوارئ تقل المشتتات ويعرض الخطر والمطلوب الآن والخطوة التالية.

رفض المستخدم أو تأجيله لا يؤدي إلى الضغط عليه؛ يسجل القرار ويشرح الأثر وتحدد المتابعة المناسبة.
