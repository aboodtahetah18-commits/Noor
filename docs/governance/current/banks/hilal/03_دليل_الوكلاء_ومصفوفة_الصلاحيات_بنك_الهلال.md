03 — دليل الوكلاء ومصفوفة الصلاحيات لبنك الهلال
الحالة: النسخة المعتمدة — الإصدار 1.0
الكيان: بنك الهلال — البنك التشغيلي للميزانية والتدفقات
المرجعية العليا: بنك نماء المركزي لإدارة الميزانية والشؤون المالية
التكامل الملزم: بنك ملاءة + بنك الأصول الاستثماري + أصحاب المسؤوليات المالية والمستشار الاقتصادي
مالك الوثيقة: مدير بنك الهلال الخوارزمي ضمن صلاحيات بنك نماء المركزي
التاريخ: 14 سبتمبر 2026
الغرض: تعريف جميع الوكلاء والاعتمادات والتصعيد والفصل بين الصلاحيات.

4. الفصل بين الاقتراح والاعتماد
الوكيل الذي يقترح التمويل أو زيادة بند لا يملك وحده سلطة تجاوز الحماية أو تعديل السياسة. مراجع المخاطر والامتثال مستقلان عن مسار التنفيذ ويستطيعان منع القرار داخل اختصاصهما.
5. Triggers التصعيد
تهديد التزام أساسي أو حد ملاءة.
دعم أو تحويل بين البنوك غير مغطى بتفويض صالح.
فشل دفع متكرر أو عجز متوقع قبل الاستحقاق.
تمويل يتجاوز السقف أو لا يملك مصدر سداد موثوقًا.
تعارض بيانات أو انخفاض Confidence تحت الحد المركزي.
انحراف جوهري أو اشتباه في ازدواج/تصنيف خاطئ.
6. مسؤولية المستخدم
المستخدم هو الشخص البشري الوحيد؛ بقية الأدوار وكلاء خوارزميون. لا يلزم اعتماد المستخدم للقرارات الروتينية التي تقع داخل التفويض الخوارزمي، لكن أي فعل مالي خارجي يظل بيد المستخدم ويحتاج USER_ACTION_REQUEST ثم تأكيد التنفيذ والإثبات والتحقق. ويستدعى المستخدم أيضًا عندما يكون القرار شخصيًا سياديًا أو خارج التفويض أو يتطلب قبول أثر جوهري.
