06 — سياسة التعلم والتغيير والتدقيق لبنك الهلال
الحالة: النسخة المعتمدة — الإصدار 1.0
الكيان: بنك الهلال — البنك التشغيلي للميزانية والتدفقات
المرجعية العليا: بنك نماء المركزي لإدارة الميزانية والشؤون المالية
التكامل الملزم: بنك ملاءة + بنك الأصول الاستثماري + أصحاب المسؤوليات المالية والمستشار الاقتصادي
مالك الوثيقة: مدير بنك الهلال الخوارزمي ضمن صلاحيات بنك نماء المركزي
التاريخ: 14 سبتمبر 2026
الغرض: تنظيم التعلم المقيد، إدارة التغيير، التدقيق ومؤشرات الأداء.
1. مبدأ التعلم المقيد
يتعلم بنك الهلال لتحسين التنبؤ والتوقيت والتخصيص داخل الحدود، ولا يملك تعديل Hard Guards أو الصلاحيات أو حدود السياسة أو قواعد التمويل ذاتيًا.
2. ما يتعلمه النظام
المصروف المعتاد والموسمية لكل فئة.
احتمال تجاوز بند قبل حدوثه.
موعد وصول الدخل واحتمال التأخير.
فعالية حدود البنود ومعدلات الاستخدام.
استجابة المستخدم للتذكيرات وأفضل توقيت لها.
مخاطر التمويل الداخلي والتأخر في السداد.
احتمال فشل التحويل أو عدم المطابقة.
3. ما لا يتغير بالتعلم المباشر
القواعد الصارمة، الصلاحيات، أولوية الحماية، تعريف الأموال المحمية، هرم السياسات، حدود التدخل المركزي، وأي معلمة مصنفة GOVERNED_PARAMETER.
4. دورة التغيير
OBSERVATION → PATTERN_DETECTION → ROOT_CAUSE → EVIDENCE_GATE → CHANGE_PROPOSAL → BACKTEST → STRESS_TEST → SHADOW_MODE → GOVERNANCE_REVIEW → APPROVAL → VERSION_RELEASE → MONITORING → ACCEPT/ROLLBACK

6. متطلبات الإصدار
POLICY_VERSION، ALGORITHM_VERSION، MODEL_VERSION، PARAMETER_VERSION، EFFECTIVE_DATE، CHANGE_REQUEST_ID، APPROVAL_TRACE.
7. سجل التدقيق
كل قرار مالي قابل لإعادة البناء من: البيانات المستخدمة، جودتها، السياسة والإصدار، الوكيل، نتيجة المخاطر، بوابة الصلاحية، القرار، وقت التنفيذ، نتيجة العملية، الأثر المالي، وأي استثناء.
8. الرقابة والمراجعة
مراجعة دورية للدقة والانحرافات وجودة المتابعة.
مراجعة فورية عند كسر قاعدة أو تكرار فشل الدفع أو عدم المطابقة.
للمركزي إجراء مراجعة فجائية أو فرض خطة تصحيح.
فشل خطة التصحيح يرفع الوضع إلى Restricted/Frozen حسب قرار المركزي.

10. الاحتفاظ والسجلات
تحفظ نسخ السياسات والإصدارات وسجلات القرارات والتدقيق وفق سياسة الاحتفاظ المركزية؛ لا تحذف السجلات اللازمة لإعادة بناء القرار بسبب تغيير النموذج أو الدورة.
11. الملحق الخوارزمي التنفيذي — التعلم الشخصي لبنك الهلال
يرتبط هذا الملحق بالسياسة المركزية للتعلم الخوارزمي والقرار القابل للتدقيق لمنصة نماء، وتكون أحكامها العامة حاكمة عند التعارض.
أ. يتعلم بنك الهلال خط الأساس الشخصي لكل بند من المتوسط والوسيط والربعيات والتكرار والتاجر ويوم الأسبوع والموسمية، ولا يعتمد المتوسط وحده.
ب. لكل بند BUDGET_FLEXIBILITY_SCORE يقدّر مقدار الخفض الممكن دون الإخلال بالأساسيات أو إنتاج رفض متكرر من المستخدم؛ ويحدّث تدريجيًا ضمن MAX_PARAMETER_DELTA_PER_CYCLE.
ج. يراقب MERCHANT_COST_CONCENTRATION لتمييز ما إذا كان الانحراف ناتجًا عن عدد الزيارات أو ارتفاع تكلفة تاجر محدد، ويقترح أقل تغيير سلوكي يحقق الهدف.
د. قبل أي إعادة توزيع، يستقبل الهلال قيود الالتزامات والأهداف والسيولة والاستثمار ذات الصلة، ولا يعتبر كامل الرصيد مبلغًا قابلًا للتخصيص.
هـ. في التمويل الداخلي يتعلم قدرة السداد الفعلية، التأخر، الأثر على البنود المرنة، ونسبة إعادة بناء المصدر؛ ولا يرفع سقف التمويل تلقائيًا بسبب نجاح سداد سابق.
و. كل توصية ميزانية مؤثرة تسجل BASELINE_VERSION وFLEXIBILITY_SCORE_VERSION وFORECAST_ERROR وWHY_THIS_AMOUNT.
ز. بعد كل دورة، يقارن المقترح بالفعلي ويصنف النتيجة، ويستخدم النتيجة لتحديث المعايرة لا لتغيير القواعد الصارمة.
ح. الذكاء الاصطناعي — إن استخدم — لا يحسب السقف المالي النهائي منفردًا، بل يشرح مخرجات هذه الخوارزميات أو يقترح فرضيات تعاد للتحقق حسابيًا.
12. التكامل مع منظومات التحليل والتعلم المركزي
أ. لا يعمل تعلم بنك الهلال كذاكرة مستقلة؛ بل يقرأ ويكتب عبر طبقة الذاكرة المالية والتعلم والتحقق المشتركة في نماء.
ب. عند تحليل الميزانية والإنفاق والالتزامات التشغيلية يستدعي البنك النتائج اللازمة من منظومة الالتزامات والديون والتحليل الاستباقي، ويستدعي منظومة المخاطر المركزية والتحليل الاستباقي عندما يكون الأثر على السيولة أو الاستقرار جوهريًا.
ج. لا يعيد بنك الهلال حساب نتيجة تخصصية حديثة وصالحة صادرة من منظومة أخرى؛ يستخدم نتيجة التسليم البيني مع مصدرها وإصدارها وثقتها، ويطلب إعادة التحليل فقط عند التقادم أو تعارض البيانات أو تغير الحدث.
د. التعلم الشخصي يمر بالمراحل: ملاحظة → نمط مشتبه → نمط مرجح → نمط معتمد، ولا تعد الموافقة أو الرفض من المستخدم وحدهما دليل نجاح أو فشل؛ المرجع الأقوى هو النتيجة الفعلية بعد التنفيذ والمتابعة.
هـ. يجوز للتعلم تحسين توقعات المصروف، الموسمية، المرونة، توقيت التنبيه، ودقة التوقع داخل الحدود النافذة، ولا يجوز له تغيير قاعدة صارمة أو أولوية التزام أو حد حماية أو مصفوفة صلاحيات.
و. أي اقتراح تغيير جوهري ينتقل إلى سجل تغيير خوارزمي يحتوي الدليل، السبب الجذري، القيمة قبل وبعد، الاختبارات، جهة الاعتماد، تاريخ النفاذ، وشرط التراجع.
ز. أي معاملات أو أوزان مرجعية غير مستندة إلى سياسة نافذة تبقى معاملات تنفيذ/اختبار ذات إصدار، ولا تتحول إلى سياسة بمجرد تحسن الأداء.
ح. بعد كل دورة مالية يسجل البنك: المتوقع مقابل الفعلي، سبب الانحراف، أثر قرار المستخدم، جودة البيانات، وما إذا كان التعلم مؤقتًا أو قابلًا للتعميم الشخصي.
