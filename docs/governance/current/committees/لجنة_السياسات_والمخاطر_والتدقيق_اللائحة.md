لائحة لجنة السياسات والمخاطر والتدقيق
الهدف المؤسسي
الحفاظ على سلامة السياسات والحدود والقواعد الصارمة وجودة القرارات والرقابة والتدقيق عبر منظومة نماء.
الدورية
ربع سنوية، مع مراجعة شاملة نصف سنوية وسنوية.
التشكيل
الرئيس: مدير بنك نماء المركزي.
نائب الرئيس: المستشار الاقتصادي.
الأعضاء الدائمون: مسؤول الميزانية والإنفاق، مسؤول الالتزامات، مسؤول الاستثمار، مسؤول السيولة والحماية.
أعضاء بحسب الموضوع: مراجع المخاطر المركزي، مديرو البنوك، وأصحاب السياسات محل المراجعة.
أمين اللجنة: أمين السر المركزي.
نطاق الاختصاص
السياسات، الحدود، المخاطر، الالتزام، التدقيق، جودة القرارات، ونتائج اختبارات القبول.
الصلاحيات
اقتراح خفض المخاطر، مراجعة الالتزام، واعتماد التحسينات التشغيلية غير الجوهرية ضمن التفويض.
الحدود
لا ترفع حدود المخاطر الجوهرية ولا تعدل القواعد الصارمة نهائيًا.
مسؤوليات الأعضاء
تقديم نتائج التدقيق والاختبارات والمخاطر، تحليل السبب الجذري، واقتراح ضوابط وتحسينات قابلة للقياس.
تعارض المصالح
مالك السياسة محل المراجعة لا ينفرد باعتماد تعديلها؛ يوثق رأيه ويشارك كمصدر اختصاص مع مراجعة مستقلة.
التصعيد
يرفع للمجلس عند تغيير سياسة أساسية، رفع المخاطر، تعديل قاعدة صارمة، أو وجود خلل رقابي جوهري.
المخرجات والسجلات
تقرير الحوكمة والمخاطر، سجل السياسات والتغييرات، نتائج اختبارات القبول، سجل الاستثناءات، الأدلة، وخطة المعالجة.
مؤشرات الأداء
عدد الثغرات المفتوحة، زمن المعالجة، نتائج الاختبارات، تكرار المخالفات، نسبة الالتزام، وجودة سجل القرارات والتدقيق.
متابعة التنفيذ والبت النهائي
يتابع مدير بنك نماء المركزي الإغلاق، مع إسناد كل إجراء تصحيحي غير مالي إلى مالك السياسة أو النظام. أي إجراء مالي ناتج عن المعالجة ينتقل إلى بروتوكول التنفيذ البشري. مجلس نماء الأعلى للقرارات الكبرى والنهائية؛ وما داخل التفويض تعتمد اللجنة دون تعديل Hard Guard أو تنفيذ مال.
ضابط حوكمة التعلم الخوارزمي
تتولى اللجنة رقابة طبقة التعلم المقيد على مستوى المنظومة. تشمل المراجعة: جودة البيانات، دقة النماذج، الانجراف، التحيز، معدلات التراجع عن الإصدارات، سلامة حدود المعلمات، الالتزام بـBacktest وStress Test وShadow Mode، وقابلية إعادة بناء القرار. لا يعد تحسن الأداء التاريخي وحده سببًا كافيًا للنشر. كل تغيير يمس سياسة أو صلاحية أو Hard Guard أو تعريف مال محمي يظل تغييرًا حوكميًا ولا يتحول إلى تعديل آلي. وتراجع اللجنة دوريًا ما إذا كان الذكاء الاصطناعي — إن استخدم — بقي داخل دوره المساعد ولم يتحول إلى مصدر قرار مالي غير قابل للتدقيق.
المرجعية المركزية لدورة القضية والاجتماع والقرار
تخضع جميع القضايا والاجتماعات والقرارات والمتابعات والإغلاقات الخاصة بهذه اللجنة للسياسة المركزية لإدارة القضايا والاجتماعات والقرارات والمتابعة — الإصدار 1.0. وتقتصر هذه اللائحة على تحديد الاختصاص والتكوين والصلاحيات والحدود الخاصة باللجنة. عند التعارض تطبق السياسة الأعلى والقواعد الصارمة، ولا يعد إغلاق جلسة الاجتماع أو تثبيت القرار إغلاقًا للقضية ما لم تستكمل المتابعة والتسوية ومراجعة النتيجة والتعلم المطلوب.
ملحق تشغيلي 2026-09-19 — الدورية والمداولة الحية
هذه لجنة دائمة، وتعقد أربعة اجتماعات سنويًا على الأقل، مع جواز زيادة التواتر وفق الدورة المالية أو مستوى المخاطر. الاجتماع الطارئ يضاف ولا يلغي الاجتماع الدوري التالي. في كل اجتماع يدار النقاش كمداولة فعلية: تعرض كل جهة طلبها أو نسبتها ومبرراتها وأثرها والحد الأدنى المقبول، ويسمح بالاعتراض والرد والبدائل قبل صياغة مشروع القرار. يحدّث أمين السر المحضر الحي ثم يرسله للمستخدم للتعميد قبل انعكاس القرارات على النظام.
ملحق تكاملي — حوكمة البناء والتعلم الخوارزمي
1- هذه اللجنة هي بوابة الحوكمة للتغييرات الجوهرية في النماذج والمعلمات والسياسات والصلاحيات التي تقترحها طبقة التعلم أو نتائج التشغيل.
2- مسار التغيير القياسي: ملاحظة → نمط → تحليل سبب جذري → بوابة أدلة → مقترح تغيير → اختبار خلفي → اختبار ضغط → وضع ظل عند الحاجة → مراجعة اللجنة → اعتماد الجهة المختصة → إصدار → مراقبة → قبول أو تراجع.
3- كل طلب تغيير يجب أن يبين القيمة أو السلوك قبل وبعد، مصدر الدليل، درجة الثقة، النطاق المتأثر، مخاطر التغيير، وخطة التراجع.
4- التحسن التاريخي وحده لا يكفي لاعتماد تغيير؛ يجب فحص الاستقرار، الانحراف، الأثر على الفئات الحساسة، والتعارض مع السياسات الأعلى.
5- لا يجوز للتعلم تغيير Hard Guard أو تعريف المال المحمي أو AUTHORITY_MATRIX أو سلطة التنفيذ البشري تلقائيًا.
6- مراجع المخاطر المركزي وظيفة رقابية خلفية، ولا يضاف إلى قائمة المسؤولين أو المستشارين الظاهرين للمستخدم.
