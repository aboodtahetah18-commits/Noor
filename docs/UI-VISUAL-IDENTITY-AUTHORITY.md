# مرجع السلطة البصرية الصارم — منصة نماء

**الحالة:** ملزم أثناء مرحلة إكمال تصميم الواجهة.

## الهدف
إنهاء تصميم واجهة نماء كاملًا قبل العودة إلى أي توسع آخر، مع منع أي انحراف عن الهوية البصرية المعتمدة.

## ترتيب السلطة
1. المرجع المركزي للهوية البصرية ونظام التصميم لمنصة نماء.
2. NDOS frozen tokens والأصول الرسمية المسجلة داخل `public/brand/ndos`.
3. الشاشات التي اعتمدها المستخدم فعليًا داخل المنصة.
4. الصور التوضيحية والنماذج المولدة تستخدم لشرح الترتيب فقط، ولا تصبح أصلًا بصريًا حاكمًا إذا خالفت الهوية.

## قواعد الشعار
- يمنع كتابة كلمة «نماء» كنص بهدف محاكاة الشعار.
- يمنع تركيب الورقة مع الكلمة يدويًا.
- يمنع إعادة تلوين الشعار أو تطبيق CSS filters عليه.
- يستخدم أصل الشعار الرسمي المناسب للسطح فقط.
- الحد الأدنى للشعار الكامل على الهاتف 88px.
- في الشريط العلوي للهاتف يكون الشعار في **المركز الهندسي للشاشة**، لا بين مجموعتي الأزرار بطريقة قد تزحزحه بصريًا.
- القائمة الجانبية جهة اليمين، وأزرار المستخدم/المظهر جهة اليسار، ولا يجوز أن تغيّر موضع الشعار.

## قواعد الخط والألوان
- الخط التشغيلي: Noto Sans Arabic فقط.
- لا ألوان raw hex في مكونات الواجهة؛ جميع الألوان من design tokens.
- لا اختراع لون أو تدرج أو ظل أو زخرفة جديدة خارج المرجع.
- الوضعان الفاتح والداكن يستخدمان القيم المعتمدة فقط.

## قواعد التخطيط
- RTL كامل.
- المسافات، أنصاف الأقطار، ارتفاعات الأزرار والأيقونات من التوكنز فقط.
- لا مكوّن جديد إذا كان له نظير معتمد موجود.
- إذا لم يوجد مكوّن مناسب، يسجل Design Gap بدل ابتكار حل بصري عشوائي.

## قاعدة الصور والنماذج
الصورة المولدة ليست مصدر حقيقة للهوية. عند التعارض بين الصورة وبين أصل الشعار أو التوكنز أو الواجهة المعتمدة، **يفوز المرجع الرسمي**.

## حماية التنفيذ
يفشل CI إذا:
- اختفى أصل الشعار الرسمي.
- عاد تركيب الشعار من نص + ورقة.
- تحرك شعار الهاتف عن المركز الهندسي.
- صغر الشعار الكامل عن 88px.
- دخل لون raw hex في واجهة الدردشة.
- تم استخدام CSS filter لإعادة تلوين أصل الهوية.

## مرحلة المشروع الحالية
حتى اعتماد المستخدم اكتمال تصميم الواجهة:
- الأولوية هي الواجهة وتجربة الاستخدام فقط.
- Vercel auto-deploy يبقى موقوفًا.
- لا يعتبر أي تصميم نهائيًا قبل المراجعة البصرية واعتماد المستخدم.
