# مستقبلي — حزمة التسليم النهائية للتنفيذ

هذه الحزمة هي المرجع الوحيد الذي يجب أن يستخدمه فريق بناء المنصة للهوية والواجهة.

## ترتيب الأولوية عند وجود أي تعارض
1. `01_SOURCE_OF_TRUTH/MUSTAQBALI_UIUX_MASTER_IDENTITY_AND_DESIGN_LOCK.md`
2. `02_IMPLEMENTATION_SPEC/MUSTAQBALI_FINAL_IMPLEMENTATION_SPEC_V1.md`
3. الصور داخل `03_APPROVED_VISUAL_REFERENCES/`

أي ملف أو صورة سابقة خارج هذه الحزمة لا تعد مرجعاً معتمداً للتنفيذ.

## قواعد غير قابلة للاجتهاد
- اسم المنتج: **مستقبلي**
- العبارة: **إدارة أذكى لحياتك المالية**
- الالتزام بالشعار المعتمد وعدم استبداله برمز العملة.
- رمز العملة مرجع لعرض المبالغ فقط.
- الالتزام بالخط والهوية والألوان المحددة في ملف Source of Truth.
- Desktop وMobile تجربتان متكاملتان وليستا مجرد تصغير مباشر.
- على الجوال: تقليل الـscroll، واستخدام عمودين للحقول القصيرة عندما يسمح المحتوى.
- المسار الرئيسي على الجوال = صفحة كاملة؛ الإجراء الفرعي = Bottom Sheet / Modal عند ملاءمته.
- الـTop Bar والـMobile Header أغمق قليلاً من سطح المحتوى.
- الـSidebar قابلة للطي وإعادة الإظهار دائماً.
- لا يتم اختراع Style أو Logo أو Palette أو Typography جديدة أثناء التنفيذ.

## ما لا يوجد في الحزمة
تم استبعاد التصاميم التجريبية والمراجع القديمة عمداً حتى لا تسبب تضارباً أثناء البناء.
