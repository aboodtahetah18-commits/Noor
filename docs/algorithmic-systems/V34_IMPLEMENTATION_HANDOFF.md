# حزمة منظومات نماء الخوارزمية — تسليم التنفيذ V34

## الحالة
هذا الفرع يضيف أساسًا تقنيًا مرجعيًا لمنظومات نماء دون تفعيل نشر أو تعديل بيئة الإنتاج.

## القواعد الحاكمة
- المستخدم هو منفذ أي فعل مالي خارجي.
- الدخل المتوقع لا يعد سيولة متاحة قبل تحققه.
- الأموال المحمية والمحجوزة لا تعامل كمال حر.
- التعلم مركزي ومقيد ولا يغير القواعد الصارمة.
- كل قرار حساس يجب أن يحتفظ بمراجع الإصدارات والسياسات.
- جميع النصوص الظاهرة للمستخدم عربية.
- الخوارزميات الخلفية لا تظهر كشخصيات مستقلة؛ المسؤولون هم واجهة الحوار.
- الاجتماعات مداولات منظمة: عرض، اعتراض، رد، تنازل، بديل، تصعيد، وتوثيق للخلاف.

## المكونات المرفوعة
- أنواع المجال وحالات البيانات والقرار.
- محرك درجة الثقة.
- محرك تغطية الالتزامات.
- محرك أهلية المال للاستثمار.
- محرك توجيه الحالات.
- منسق دورة القرار.
- منسق المداولة والاجتماعات.
- قاموس التعريب.
- اختبارات وحدة أساسية.

## حدود هذه الدفعة
هذه الدفعة لا تربط الخدمات الجديدة بواجهات الإنتاج أو قاعدة البيانات بعد. الدمج النهائي يجب أن يطابق البنية الحالية في:
- src/domain
- src/financial-engine
- src/governance
- src/state-machines
- src/repositories

## النشر
إعداد Vercel الحالي يعطل Git auto-deployments عبر vercel.json.
لا يتم أي نشر من هذا الفرع دون توجيه مستقل وصريح.
