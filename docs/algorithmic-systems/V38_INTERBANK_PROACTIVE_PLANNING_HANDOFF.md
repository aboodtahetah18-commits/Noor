# نماء — التكامل الاستباقي بين البنوك V38

الحالة: مسودة تنفيذية على فرع المراجعة فقط. لا نشر إنتاجي ولا دمج إلى main ضمن هذه الدفعة.

## الهدف
تحويل بنك الهلال وبنك ملاءة وبنك الأصول من مكونات تنتظر المستخدم إلى بنوك مؤسسية حية تراقب أوضاعها، تتنبأ باحتياجاتها، تنشئ أهدافًا نشطة، تتفاوض فيما بينها، وترفع للمستخدم ما يحتاج قرارًا أو تنفيذًا.

## القواعد المؤسسية
- بنك الهلال يملك التشغيل والميزانية والتدفقات والالتزامات التشغيلية.
- بنك ملاءة يملك الحماية والسيولة والاحتياط والطوارئ.
- بنك الأصول يملك تحليل الفرص والاستثمارات والسيولة الاستثمارية.
- بنك نماء المركزي لا ينافس البنوك في التشغيل؛ يضع السياسة، يراقب المخاطر، يحل التعارض، ويحكم التغييرات.
- أصحاب المسؤوليات يتبعون تشغيليًا مدير بنك نماء المركزي ويقدمون الرأي التخصصي للبنوك ذات الصلة.
- المدير ينسق ولا يطمس رأي المسؤول المختص.
- المستخدم ينفذ كل فعل مالي خارجي.

## دورة التخطيط والمبادرة
توقع → احتياج → هدف نشط → طلب بين البنوك → تفاوض → ترتيب أولوية → توصية/قرار → تنفيذ المستخدم → إثبات ومطابقة → متابعة → تعلم.

## خطة الاحتياج المستقبلية
كل بنك يستطيع الاحتفاظ باحتياج مستقبلي يتضمن:
- الوضع الحالي.
- الوضع المستهدف.
- الفجوة.
- الأفق الزمني.
- الأولوية.
- الحد الأدنى المقبول.
- المبلغ المثالي.
- سبب الطلب.
- المرونة والتنازلات الممكنة.
- ما لا يجوز التنازل عنه.
- مصادر التمويل الممكنة.
- درجة الثقة.

## أهداف نماء النشطة
أي احتياج مادي قريب أو مرتفع الأولوية يمكن أن يظهر كهدف نشط للمستخدم، مع البنك المالك، البنوك الداعمة، نسبة التقدم، السبب، والخطوة التالية.

## الطلبات بين البنوك
يجوز للبنك أن يطلب من البنوك الأخرى أولوية أو تخصيصًا أو تأجيلًا أو استردادًا داخل السياسة. الطلب لا يحرك المال. عند الحاجة لحركة فعلية ينشأ USER_ACTION_REQUEST للمستخدم.

## التفاوض
كل بنك يعرض:
- المبلغ المطلوب.
- الحد الأدنى.
- السبب.
- الاعتراضات.
- التنازلات المشروطة.
- الحدود غير القابلة للتجاوز.
الخلاف غير المحسوم أو نقص المال عن احتياج حرج يرفع لبنك نماء المركزي أو اللجنة المختصة.

## التكامل الخوارزمي
- منظومة الالتزامات والديون: قيود الاستحقاقات والديون.
- منظومة المخاطر المركزية: الاستقرار والسيولة واختبارات الضغط.
- منظومة الاستثمار والأهداف الذكية: ملاءمة الاستثمار والأهداف.
- طبقة الذاكرة المالية والتعلم والتحقق: النتيجة الفعلية والتعلم المقيد.

## التعلم
التعلم يحسن التوقع، توقيت المبادرة، دقة الاحتياج، المرونة، وترتيب البدائل داخل الحدود. لا يغير Hard Guard أو سياسة أو تعريف مال محمي أو AUTHORITY_MATRIX تلقائيًا.

## ما تم تنفيذه في هذه الدفعة
- عقد TypeScript للاحتياجات المستقبلية والأهداف النشطة والطلبات والمواقف بين البنوك.
- منطق تحقق وترتيب الاحتياجات.
- منطق تفاوض أولي على المال المتاح مع إشارة واضحة لحاجة المراجعة المركزية.
- قاعدة فتح قضية استباقية للاحتياجات القريبة أو مرتفعة الأولوية.
- اختبارات وحدة للسلوك الأساسي.

## ما لم يتم في هذه الدفعة
- لا تغيير للواجهة أو الدردشة.
- لا تغيير لقواعد النشر.
- لا دمج إلى main.
- لا تنفيذ مالي تلقائي.
- لا تحويل القيم المرجعية إلى سياسة معتمدة.
