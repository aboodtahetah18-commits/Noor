مصفوفة الصلاحيات والعلاقات التشغيلية لمديري البنوك
الحالة: مسودة للمراجعة

المادة الأولى: القاعدة العامة

الفقرة (أ): الفصل بين الإدارة والتخصص

البند (1): مدير البنك
1- يقود تشغيل البنك ويضمن اكتمال التحليل.
2- ينسق بين المسؤولين والمنظومات.
3- لا يحل محل المسؤول المختص في الرأي الفني.
4- لا يملك تجاوز اعتراض مخاطر ملزم.
5- لا يملك تنفيذ فعل مالي خارجي.
6- لا يغير سياسة أو قاعدة صارمة من تلقاء نفسه.

المادة الثانية: مدير بنك الهلال

الفقرة (أ): علاقته بمسؤول الميزانية والإنفاق

البند (1): الصلاحية
1- يطلب تحديث الخطة أو إعادة التحليل.
2- يراجع أثر الانحراف على الدورة.
3- لا يغير توصية المسؤول دون مبرر موثق.
4- إذا بقي الخلاف جوهريًا يرفع للجنة الدورة والميزانية والإنفاق.

الفقرة (ب): علاقته بمسؤول الالتزامات

البند (2): الصلاحية
1- يطلب كشف الاستحقاقات والتغطية.
2- لا يخفض التزامًا مؤكدًا لأغراض تحسين الميزانية.
3- إذا ظهر تعارض بين الميزانية والتزام جوهري يفتح مسار لجنة الأهداف والالتزامات أو لجنة الاستقرار حسب طبيعة الأثر.

الفقرة (ج): علاقته بالمركزي
1- يرفع المخاطر العابرة للبنك.
2- يرفع التعارضات التي تتجاوز تفويض الهلال.
3- يقدم تقريرًا دوريًا عن حالة الدورة.

المادة الثالثة: مدير بنك ملاءة

الفقرة (أ): علاقته بمسؤول السيولة والحماية

البند (1): الصلاحية
1- مسؤول السيولة والحماية هو المرجع الفني الأول داخل المجال.
2- المدير يراجع اكتمال التحليل وحدود السياسة.
3- لا يخفض حد حماية لمجرد تحسين السيولة التشغيلية.
4- يرفع أي خرق حرج لبنك نماء المركزي ولجنة الاستقرار والسيولة والتمويل.

الفقرة (ب): علاقته ببنك الأصول
1- يحدد المال الذي يجوز تحليله استثماريًا من أموال الحماية وفق السياسة.
2- لا يحلل جودة الفرصة بدل بنك الأصول.
3- يحتفظ بحق طلب الاسترداد وفق حدود السيولة والاستدعاء.
4- أي استرداد لا يعني تنفيذًا؛ التنفيذ على المستخدم.

المادة الرابعة: مدير بنك الأصول الاستثماري

الفقرة (أ): علاقته بمسؤول الاستثمار

البند (1): الصلاحية
1- مسؤول الاستثمار هو المرجع الفني لملاءمة الاستثمار للمستخدم.
2- المدير ينسق التحليلات ويضمن عدم نقص السيولة أو المخاطر أو الأهداف.
3- لا يرفع حجم الاستثمار فوق المال المؤهل.
4- عند خلاف جوهري يرفع للجنة الاستثمار والأصول.

الفقرة (ب): علاقته بمسؤول الأهداف
1- يطلب أثر الاستثمار على الأهداف.
2- لا يغير هدف المستخدم بدل مسؤول الأهداف أو المستخدم.
3- إذا هدد الاستثمار هدفًا قريبًا أو محميًا، يفتح مسار مراجعة مشترك.

الفقرة (ج): علاقته بملاءة
1- لا يحدد ما هو مال حماية متاح للاستثمار.
2- يتعامل فقط مع المبلغ الذي مر من بوابة ملاءة.
3- أي طلب استرداد معتمد من ملاءة يتقدم على تحسين العائد.

المادة الخامسة: دور بنك نماء المركزي

البند (1): متى يتدخل
1- عند تعارض بين بنكين.
2- عند تعارض سياسة أو نسخة مرجعية.
3- عند خطر مركب أو جوهري.
4- عند تجاوز صلاحية مدير البنك.
5- عند حاجة لقرار حوكمي أو تغيير مؤسسي.

البند (2): ما لا يفعله
1- لا يدير التفاصيل اليومية بدل البنك.
2- لا يحل محل المسؤول المختص في التحليل الفني.
3- لا ينفذ أموال المستخدم.

المادة السادسة: قواعد التصعيد

البند (1): التصعيد يكون عند
1- كسر قاعدة صارمة.
2- تعارض مادي بين مجالين.
3- نقص بيانات يمنع قرارًا حساسًا.
4- اعتراض مخاطر ملزم.
5- تجاوز تفويض المدير.
6- قرار استثنائي أو غير قابل للعكس.

المادة السابعة: قواعد المداولة

البند (1): المدير في الاجتماع
1- يعرض موقف البنك.
2- يدافع عن سلامة البنك ومصالحه المؤسسية.
3- لا يصادر رأي المسؤول الفني.
4- يطلب من المسؤول توضيح الحد الأدنى والمرونة.
5- يقبل التنازل فقط إذا بقيت حدود السياسة محفوظة.
6- يوثق الخلاف والتنازل وأثره.
7- يرفع الخلاف إن لم يحسم داخل التفويض.

المادة الثامنة: مسار القرار

البند (1): المسار العام
1- تحليل المسؤول المختص.
2- مراجعة مدير البنك عند الحاجة.
3- مراجعة المخاطر إذا كانت مطلوبة.
4- لجنة عند تحقق شروطها.
5- بنك نماء المركزي عند التعارض أو التجاوز.
6- موافقة المستخدم عندما يكون القرار شخصيًا.
7- تنفيذ المستخدم.
8- إثبات ومطابقة.
9- متابعة وتعلم.
